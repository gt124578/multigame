À propos

Arcadia, ce sont des jeux à plusieurs, directement dans le navigateur : un salon, un code de quatre lettres, et toute la bande joue ensemble. Gratuit, sans publicité, sans rien installer.

Qui fait Arcadia ?

Un projet entre potes, lancé par Amiel avec Nicolas et Gabriel, et développé avec l'aide de Claude (Anthropic). Tout a commencé avec Duo Drift, une course en vue du ciel pour jouer à deux ; le salon a grandi jusqu'à une douzaine de jeux.

Une idée, un bug ? Écris-nous sur GitHub. Les nouveautés de chaque version sont dans « Nouveautés », sur l'accueil.

Confidentialité

Arcadia ne te demande ni e-mail, ni mot de passe, ni vrai nom, et n'affiche aucune publicité.

  • Dans ton navigateur : ton pseudo, ta couleur, ta liste d'amis, tes réglages (volume, graphismes) et tes scores. Ils restent sur ton appareil ; effacer les données du site les supprime.
  • Sur le serveur de jeu : pendant une partie, le relais transmet les messages entre les joueurs du salon (positions, coups, chat) sans les garder. Il sert aussi à montrer à tes amis que tu es en ligne (pseudo, couleur, code ami).
  • Compte en ligne (si tu choisis un mot de passe) : ton profil (pseudo, couleur, code ami, amis) est chiffré dans ton navigateur avec ton mot de passe avant d'être rangé en ligne. Le serveur ne reçoit jamais ton mot de passe et ne peut pas lire ton profil. Revers de la médaille : un mot de passe oublié ne peut pas être récupéré.
  • Sauvegardes d'Odyssée : si tu joues à Odyssée, ta partie est rangée en ligne sous ton code ami, pour la retrouver sur un autre appareil. Rien d'autre n'y est attaché.
  • Journal des plantages : quand un jeu plante, un rapport technique (jeu, message d'erreur) est noté dans ton navigateur, pour aider à corriger le bug. Il ne contient pas tes messages.

Le site est hébergé par GitHub Pages et les polices viennent de Google Fonts : comme pour tout site, ces services voient ton adresse IP quand ils t'envoient les fichiers.
